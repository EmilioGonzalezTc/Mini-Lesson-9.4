>## About the Project
This project explores housing price prediction using Linear Regression. I analyzed different house characteristics. After exploring the data and selecting relevant variables, I developed and compared three different regression models. The best model used eight variables and achieved an R-squared of approximtely 0.7568 on the test dataset. The results show how data analysis and variable selection can help improve price predictions.
